# ASCII ART

Python의 Pygame과 NumPy를 학습하면서 3D 그래픽의 기초 원리를 직접 구현하는 개인 학습 프로젝트입니다.

## 프로젝트 목표

- Pygame을 이용한 실시간 그래픽 구현
- NumPy를 이용한 3D 좌표 계산
- ASCII 문자 기반 3D 렌더링
- 회전 및 성장 애니메이션 구현
- 직접 디자인한 ASCII 아트 제작

## 사용 기술

- Python 3.11
- Pygame
- NumPy

## 현재 진행 상황

- [x] Pygame 기본 화면 생성
- [x] ASCII 눈 내리는 애니메이션
- [x] NumPy를 활용한 3D 좌표 계산
- [x] 3D ASCII 정육면체 회전
- [x] ASCII 크리스마스트리 제작
- [ ] 사용자 디자인 기반 ASCII 아트 제작

## 실행 방법

필요한 라이브러리 설치:

```bash
python -m pip install -r requirements.txt
```

프로그램 실행:

```bash
python source/main.py
```
